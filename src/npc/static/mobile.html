Imaginez une voix

Qwen3-TTS VoiceDesign interprète votre description et crée un aperçu vocal.

Décrivez les propriétés audibles : hauteur, résonance, grain et débit. Les préréglages fournissent une consigne en anglais et gardent la parole en français. Choisissez une voix masculine ou féminine dans les réglages ci-dessous ; ce choix reste indépendant du personnage.

La description et les réglages sont enregistrés pour vos récits. Les consignes orientent Qwen sans garantir un timbre exact. Le timbre peut varier entre les passages : ce mode ne fige pas une identité vocale.
